# Wokyintosh 1.0.0

The first public release of **Wokyintosh** — a retro Macintosh-inspired system monitor for macOS.

## Highlights

- Live CPU, RAM, SSD and network information
- Apple Music and Spotify Now Playing
- Album artwork
- Local weather
- Automatic light/dark appearance that follows macOS
- Native AppKit + WebKit implementation
- Classic Macintosh-inspired visual design

## Requirements

- macOS 13 Ventura or later

## Installation

Download `Wokyintosh-1.0.0-macOS.zip`, extract it, and move `Wokyintosh.app` to Applications.

### Gatekeeper notice

This version is not Apple-notarized because the project does not yet use an Apple Developer ID.

macOS may therefore block the first launch. Control-click the app and choose **Open**. If necessary, go to **System Settings → Privacy & Security** and choose **Open Anyway**.

Only bypass Gatekeeper for a copy downloaded from this official GitHub repository.

## Permissions

Wokyintosh may request:
- Location access for local weather
- Automation access to Apple Music or Spotify for Now Playing information
