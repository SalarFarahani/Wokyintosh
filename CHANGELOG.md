# Changelog

## 1.0.0 — 2026-09

Initial public release.

### Added
- Native macOS application shell
- Live CPU, RAM, SSD and network monitoring
- Apple Music and Spotify Now Playing support
- Album artwork
- Local weather
- Automatic system-based light/dark appearance
- Retro Macintosh-inspired dashboard
- Short startup sequence
- Wokyintosh app icon

### Notes
- Requires macOS 13 or later.
- This release is ad-hoc signed and is not Apple-notarized.
