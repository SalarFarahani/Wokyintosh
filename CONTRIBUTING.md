# Contributing

Thanks for your interest in Wokyintosh.

For version 1.x, the simplest workflow is:

1. Fork the repository.
2. Create a branch for your change.
3. Test the build on macOS 13 or later.
4. Open a pull request with a concise description of the change.

Please keep the retro Macintosh visual identity intact unless the change is specifically about a new theme or appearance option.
